# ロボッカー 単体・結合テスト結果

対象は現行 `robot_final.ino`（自動後退しないメイン版）。添付資料は試験設計の参考として使用した。添付 main.c 自体の動作試験ではない。対象のSHA256と実施時刻は results.json と各Excelの実施概要に記録。

## 実施結果

- 単体テスト：34件 PASS / 34件
- 結合テスト：29件 PASS / 29件
- Arduino Uno実機用ビルド：成功。Flash 11,904 / 32,256 bytes、SRAM 642 / 2,048 bytes。
- 設計書整合検証：57関数・25図・40要件、ダウンロードコード一致、Excel 58シートとHTML一致、生成の再現性、JavaScript構文を確認し合格。

Excelの入力欄は実行したテストコード、期待値欄はassert条件。実測欄のPASSはスタブで取得した内部状態・PWM・GPIO等が条件に一致したことを示す。実際の走行距離や回転角度を計測した結果ではない。初回の不合格で実行は終了するため、後続ケースを合格扱いにはしない。

単体は個別関数・状態遷移・境界値を直接呼び出す試験、結合はリモコン入力→loop→走行出力、または走行・障害物・音楽の連携を確認する試験として分類。全57関数の網羅率や分岐網羅率は測定しておらず、完全網羅を保証する結果ではない。

## 主な確認範囲

- 前後左右、斜め4方向と押下順8通り、遅い入力、左右PWM差、OK停止、IRリピート無視。
- 前方障害物で停止し自動後退しないこと。手動後退、後方障害物からの前進回避、前後障害物の右旋回。
- 前方19/20/21cm、反対方向300/301ms、数字競合299/300ms、センサー確認99/100ms、回避500msなど。
- ダンスの左右動作→右回転→左回転の反復、専用曲ループ、警告中断と再開、障害物・OKで停止。
- 既存仕様では超音波タイムアウトを999cmとして扱う。これは故障時の安全性を証明する試験ではない。

## 添付資料の確認

`main.c` はLPC13xx／vs-wrc103向け、結合テストExcelはビュートローバーH8向けで、Arduinoメイン版とは機種・センサー・仕様が異なる。旧資料の「近ければバック」は今回の仕様へ適用しない。

添付Cには `whlle`、未定義 `gwtSW`/`UCG_ON`、`if(ucg_ONOFF = UCG_ON)` の代入、`else if{(` と波括弧の不整合がある。添付stub.cには未定義 `AMSTB_ucmTest_Call` があり、固定長配列に対する上限確認もない。必要ヘッダーも添付されていない。したがって添付コードを実行済み・合格とはしていない。元資料は変更せず、現行Arduino API用のスタブで現行ソース全体をコンパイル・検証した。

## 再実行

Python 3、g++、openpyxlがある環境でリポジトリのルートから実行。

```sh
python3 tests/report_results.py
python3 tests/check_guide.py
python3 tests/check_excel.py
```

`tests/robot_test.cpp` が試験本体、`tests/stubs/` がIR／PROGMEM代替、GPIO・PWM・時刻・超音波の代替は試験本体内。元のスケッチを直接読み込み、Arduinoが自動生成する関数プロトタイプだけを補ってホストでコンパイルする。製品コードの関数をコピーした別実装ではない。Excel・JSON・ログは再実行で更新される。
