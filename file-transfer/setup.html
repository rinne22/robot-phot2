このページは、実際のクラウド保存を始めるための設定ガイドです。PCへのアプリ追加、カード登録、有料サーバーは必要ありません。SupabaseのFreeプロジェクトとGitHub Pagesを使います。

ファイル管理画面へ詳しいREADMEPC-A / PC-Bテスト手順
現在は接続設定前です

管理者がSupabaseプロジェクトを作り、SQLを実行し、config.jsの公開用接続情報を設定すると利用できます。このサイトは未設定の状態で「保存できた」とは表示しません。

01　無料のSupabaseを作る

  1. Supabaseに登録し、Free組織で専用プロジェクトを作ります。カードや有料オプションは登録しません。
  2. SQL Editorでsupabase.sqlの全文を実行します。ファイル情報用DB、非公開バケット、本人専用のRLS、容量予約処理をまとめて作成します。
  3. Storageの pc-transfer がPrivateになっていることを確認します。
  4. AuthenticationでEmail/Passwordを有効にし、Site URLとRedirect URLsに実際の公開URLを登録します。

02　公開用の接続情報を入れる

Project SettingsのAPI / API KeysからProject URLとPublishable key（またはanon key）を取得し、config.jsの空欄だけを編集します。

supabaseUrl: 'https://プロジェクトID.supabase.co',
publishableKey: 'sb_publishable_公開キー',
bucket: 'pc-transfer'

service_role・sb_secret_...・データベースのパスワードは絶対に記載しません。ファイル本体はGitHubには公開されません。

03　GitHub Pagesで公開する

  1. 公開リポジトリの file-transfer/ フォルダにファイル一式を置きます。
  2. Settings → Pagesでmain / rootからの公開を設定します。
  3. https://ユーザー名.github.io/リポジトリ名/file-transfer/ を開きます。
  4. 自分のメールで登録・確認・ログインします。Supabase標準の認証メールは宛先と送信回数に制限があります。少人数なら組織のメンバーや管理者が作成したアカウントで始めます。詳細はREADMEを読んでください。

04　別のPCから取り出す

  1. PC-Aでアップロードし、必ず「保存完了」を確認します。
  2. PC-Aのブラウザを終了し、電源を切ります。
  3. PC-Bで同じURLを開き、同じメール・パスワードでログインします。
  4. 一覧からダウンロード。画像・PDF・テキストはプレビューも利用できます。

「共有」で期限付きリンクを作れば、相手はログインせず対象ファイルだけ取得できます。リンクを知る人に権限が渡るため、必要な相手だけに渡してください。

無料運用で知っておくこと

  • アプリの安全上限は1ファイル50 MB・全ユーザー合計800 MBです。SQL側で並行操作も確認し、超えるアップロードを止めます。
  • DBは400 MB、ファイル・予約は10,000件を上限とします。不要なファイルは削除してください。
  • 通信量と認証メール等の無料枠はSupabase DashboardのUsageで別途確認します。この静的サイトだけでは利用枠全体の自動監視や通信量の厳密な制御はできません。
  • 2026年11月11日確認のFreeは保存1 GB・DB 500 MB・通常送信量5 GB等。1週間非稼働で休止の対象になります。最新条件は公式料金表を確認してください。
  • PCを閉じてもクラウドに残りますが、無期限の保存・無休止のアクセスを保証するサービスではありません。重要ファイルはバックアップも取りましょう。
  • Free組織のまま運用します。コードによる自動課金・有料化はありません。
